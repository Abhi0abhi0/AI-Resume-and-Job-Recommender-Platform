#  AI Resume & Job Recommender

AI-based web app that analyzes resumes and suggests suitable job roles.

## 🔧 Tech Stack
- React.js
- Node.js, Express
- MongoDB
- Python (ML/NLP)

## ⚙️ Setup
```bash
git clone https://github.com/Abhi0abhi0/AI-Resume-and-Job-Recommender-Platform.git
cd AI-Resume-and-Job-Recommender-Platform

cd server
npm install
npm run dev


cd client
npm install
npm run dev
